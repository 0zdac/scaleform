# scaleform

Public archive of the abandonedpools Scaleform HUD addon plus the GameSense Lua port.

The original `p_scaleform` addon is an HLAE/MIGI Panorama addon for CS:GO demos and offline `-insecure` play. `scaleform.lua` is the standalone GameSense port and is kept separately because GameSense cannot directly load the addon ZIP/XML/CSS override as a MIGI addon.

## Contents

- `panorama.my.zip` — original HLAE Panorama override archive.
- `p_scaleform/` — original MIGI addon files and assets.
- `scaleform.lua` — GameSense Lua port.
- `readme-upstream.md` — upstream usage notes.
